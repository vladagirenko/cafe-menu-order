# Кафе «Смачно»: замовлення їжі за меню

Навчальний проєкт з лабораторної роботи №1 з дисципліни «Людино-машинна взаємодія» (ХНУРЕ, кафедра програмної інженерії).

Веб-застосунок, у якому відвідувач закладу харчування переглядає меню зі свого смартфона, формує замовлення та відстежує його статус без очікування на офіціанта.

**Автор:** Гиренко В. О., група ПЗПІ-25-3
**Викладач:** Мельнікова Р. В.

## Основне завдання користувача

Обрати страви з меню та оформити замовлення: QR-код на столі, меню з фільтрами алергенів, картка страви, кошик, підтвердження, номер і статус замовлення.

## Можливості

- меню за категоріями (закуски, супи, основні страви, десерти, напої);
- пошук за назвою та фільтри «Без горіхів», «Без глютену», «Без молока», «Вегетаріанські»;
- картка страви: склад, вага, ціна, алергени, кількість, побажання;
- кошик зі зміною кількості, видаленням і підрахунком суми;
- екран підтвердження з номером столу;
- номер замовлення та статус: «Прийнято» → «Готується» → «Готово»;
- індикатор кроку («Крок X з 4»), адаптивна верстка під смартфон.

## Запуск

Збирання не потрібне. Відкрийте `index.html` у браузері (подвійний клік). Для перегляду як на телефоні натисніть F12 і ввімкніть режим пристрою (ширина близько 390 px).

## Технології

HTML5, CSS3, JavaScript (без бібліотек і бекенду). Меню зберігається у `js/menu-data.js`, кошик і замовлення існують, поки відкрита сторінка.

## Сценарій для демонстрації

1. Категорія «Основні страви», фільтр «Без горіхів».
2. Відкрити «Паста з томатним соусом» і додати в кошик.
3. У «Напоях» додати чай і сік.
4. Кошик, «Оформити», «Підтвердити замовлення».
5. Спостерігати статус до «Готово».

Оплата відбувається в закладі, онлайн-оплати немає.
